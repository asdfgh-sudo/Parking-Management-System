系统说明
  • 车辆进出管理：登记车辆入场，自动分配空闲车位并生成停车订单；黑名单车辆禁止入场。
  • 车位管理：维护车位编号与区域，实时更新空闲 / 占用 / 故障三种状态。
  • 订单计费管理：停车订单自动生成，支持阶梯计费与缴费结算，缴费后自动释放车位。
  • 收费规则配置：自定义首小时费用、续时单价、单日封顶与月租价格。
  • 数据统计：汇总今日订单、今日营收、未支付订单等核心运营指标。
  • 黑名单管理：录入欠费 / 违规车辆，入场时自动拦截。
